## 먼저 읽을 것 — 이 시트가 종전과 다른 점

**종전 시트는 순서대로 밟으면 스스로를 파괴했다.** 4회차 앞머리에 초기화가 있어서, 위에서부터 내려가면 **5~12회차의 재료가 통째로 사라졌다.** 그래서 순서를 다시 짰다.

| | 종전 | 지금 |
|---|---|---|
| 짜임 | 주제별 14회차 | **준비물별 25묶음** |
| 필드 편집 창 | 6개 회차에 흩어져 **6번 연다** | **S3에서 한 번** |
| 캐릭터 편집 창 | 7개 회차에 흩어짐 | **S5·S6·S7 연속** — 창을 거의 안 나온다 |
| 캐릭터 200명·작품 60개 | 손으로 4~6시간 | **엑셀 시드 왕복 40분**(S4) · 손 클릭 0회 |
| GB급 백업 | 따로 만들어야 함 | **S13의 900장이 저절로 만든다** |
| 대결 판 | 회차마다 다시 돌림 | **후보 10명으로 좁혀 50판 · 2분**(S14) |
| AI 실호출 | 줄마다 따로 = 약 40회 | **약 15회** — 검토 시트 하나에 여러 확인을 얹는다 |
| 전체 백업 생성 | 최대 4회 | **1회**(S23) + 마지막 안전 백업 1회 |
| 파괴적 단계 | 여기저기 · 4회차 앞머리의 초기화가 뒤를 지웠다 | **대부분 S22~S25로.** 1부에 남은 셋은 각 묶음 **맨 끝**에 뒀다(아래 ⚠️) |

**⭐ S2 + S4를 마치면 303단계 중 절반 남짓의 재료가 선다.** 거기에 S13·S21까지 하면 약 72%다.

> **전체는 25묶음 · 약 14시간이다 — 하루에 끝낼 일이 아니다.** 한 묶음이 20~90분이고 그 안은 앉은자리에서 끝난다. **며칠에 나눠 밟는 것을 전제로 짰다.**

### 순서 규칙

**번호 순서대로 밟으면 된다.** 그렇게 짠 것이고, 아래는 *왜 그 순서인가*다.

1. **S1이 맨 앞이다.** 구버전 앱이 깔린 기기는 **나중에 못 만든다.**
2. **S2~S19는 서로 파괴하지 않지만 재료 의존이 있다** — 그래서 번호를 건너뛰지 말 것. `S3 → S6·S7·S15`(필드·등급 체계) · `S4 → S5·S10·S11`(200명·60작품·값 12종) · `S6 → S7 → S8` · `S14 → S15`(쌓은 판) · `S17 → S18`(프로바이더) · `S13 → S19`(이미지)·`S13 → S23`(900장).
3. **묶음 안에서도 위에서 아래로.** 몇 자리는 순서가 곧 확인이다 — `S4`는 확인 한 줄이 준비물보다 앞이고, `S13`은 고정점을 먼저 본 뒤에야 폴더를 손대고, `S8`의 마지막 한 줄은 `S7`의 결과를 날린다.
4. **S20~S23(엑셀·백업)은 S19 다음이다.** 정본 파일에 모든 재료가 실려야 한다.
5. **S24~S25가 맨 끝이다.** 여기서 지운 것은 안 돌아온다.

> ⚠️ **"1부는 파괴가 없다"고 읽지 말 것.** 대부분은 그렇지만 셋은 아니다 — `S5`의 마지막 셋(이미지 **파일**이 지워진다) · `S16`(세계관을 통째로 지웠다 되살린다 · 프리셋 덮어쓰기) · `S8`의 마지막 한 줄(`S7`이 고친 축 이름을 되돌린다). 그 셋은 각 묶음 안에서 **맨 끝**에 뒀고 머리에 백업 지시를 달아 두었다.

### 알려 줄 것

깨진 것만 **`S6-ㄱ-3, 핸들이 한쪽만 움직임`** 정도로 알려 주면 된다. 한 묶음이 다 통과하면 **`S6 통과`** 한 줄이면 그 묶음이 통째로 닫힌다. 못 밟은 것은 **못 밟았다고** 적어 주면 된다 — 통과로 세지 않는 것이 요점이다.
