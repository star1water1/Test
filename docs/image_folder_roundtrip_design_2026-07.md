## 1. 기능 요약과 용어

**정리 폴더**: 사용자가 지정하는 SAF 폴더 하나. 두 방향으로 쓴다.

- **받아오기(PR-1)**: 정리 폴더를 스캔해 ① 새 파일(토큰 없음)을 라이브러리로 편입하고
  ② 토큰 있는 파일(앱이 내보낸 사본)의 폴더 위치를 캐릭터 배정·링크에 반영한다.
  처리한 원본은 폴더 안 `_처리됨/`으로 이동한다.
- **정리용 내보내기(PR-2)**: 현재 라이브러리를 폴더 구조(캐릭터별/미배정/세트)로 사본
  내보내기. 파일명에 정체성 토큰을 심어, 바깥에서 폴더만 옮긴 뒤 받아오기가 그 재배열을
  메타데이터에 반영할 수 있게 한다.

**설계 불변식** (전 항목에 우선):
- **앱이 원본을 소유한다.** 폴더의 파일은 유입 대기물 또는 내보낸 사본이다. 정리 폴더에서
  파일이 없어져도 앱 데이터는 불변 — **"폴더에 없음 ≠ 삭제"**. 삭제는 인앱 명시 조작뿐.
- **받아오기는 메타데이터(배정·링크)와 신규 편입만 쓴다.** 기존 이미지 파일 내용을 덮어쓰는
  경로는 없다(내보낸 사본을 바깥에서 편집해도 앱 원본은 그대로 — 교체는 2차 후보도 아님,
  하려면 별도 명시 기능으로).
- **캐릭터 배정만 다룬다.** 작품·세계관 배정은 읽지도 쓰지도 않는다(그쪽은 엑셀 경로 유지).
- 양방향 동기화(폴더가 원본)는 **영구 반려**(결정 D8) — 이 문서 범위에서 재론하지 않는다.

## 2. 이름 토큰 규약 (결정 D4)

- 내부 파일명은 `char_<UUID>.jpg`·`img_<UUID>.jpg` 형태다(`StorageAnalyzer.IMAGE_PREFIXES`).
  **토큰 = 그 UUID의 소문자 16진 앞 12자**(하이픈 제거 기준). 12자(48비트)면 수천 장에서도
  충돌 확률이 무시 가능하고, 내보내기 시점에 전 파일 대조로 유일성을 **검증**한다 — 겹치면
  겹친 파일들만 전체 UUID로 연장(결정적).
- 내보내기 파일명: **`[라벨]-[번호].[토큰].[확장자]`** (예: `가온-01.3f9ak2c407b1.jpg`).
  - 라벨 = 캐릭터명(미배정은 `이미지`)을 파일명 안전 문자로 정리(금지 문자 `\/:*?"<>|` →
    `_`, 앞뒤 공백 제거, 빈 결과면 `이미지`). **라벨·번호는 사람용일 뿐** — 정체성은 토큰만.
  - 번호 = 폴더 안 순번 2자리(01부터). 정렬용일 뿐 의미 없음.
- 받아오기 매칭: 파일명 끝에서 두 번째 점 구간을 토큰 후보로 읽는다(`이름.토큰.확장자`).
  스캔 시점에 앱 관리 파일 전체로 "토큰 → 내부 경로" 사전을 같은 규칙(12자 + 연장분은 전체
  UUID도 등재)으로 만들고 **정확 일치만** 매칭한다. 후보가 사전에 없으면 = 토큰 아님 =
  신규 파일로 취급(점 있는 일반 파일명과 자연 구분된다). 같은 토큰이 폴더에 두 번 있으면
  그 토큰은 **반영 보류 + 고지**(어느 위치가 의도인지 알 수 없다 — 변수 제어).
- UUID 형태가 아닌 내부 파일명(레거시)은 토큰을 만들 수 없다 → 내보내기에서 개수 고지 후
  제외(받아오기 위치 반영 불가 — 신규 편입만 가능한 파일로 남는다).

## 3. 폴더 규약 (결정 D3·D5)

예약 폴더명은 `_` 접두다. 스캔 대상은 정리 폴더 직속 + 1단계 하위 폴더까지(더 깊은 계층은
개수만 고지하고 무시 — 규약을 단순하게 유지).

| 위치 | 신규 파일(토큰 없음) | 토큰 파일(기존 이미지) |
|---|---|---|
| `<캐릭터명>/` (캐릭터 정확 일치) | 편입 + 그 캐릭터 배정 → 자동 링크가 묶음 | 캐릭터 배정을 그 캐릭터로 **이동** |
| `<기타 이름>/` (일치 캐릭터 없음) | 편입 + 미배정 + **그 폴더끼리 링크 세트**(2장 이상일 때, 수동 UUID 그룹) | 배정 변경 없음 + 그 폴더 세트로 링크(기존 수동 링크 규약대로 흡수·병합 판정) |
| 정리 폴더 직속 · `_미배정/` 직속 | 편입 + 미배정(링크 없음) | 캐릭터 배정 **전부 해제**(미배정으로 이동 — 기존 배정 해제 규약: 파일 유지·라이브러리 승격) |
| `_미배정/<세트명>/` | 편입 + 미배정 + 링크 세트 | 배정 해제 + 그 세트로 링크 |
| `_공유/` | 편입 + 미배정(고지) | **반영 제외**(공유 이미지는 위치 이동의 의미가 모호 — 고지만) |
| `_처리됨/` | 스캔 제외 | 스캔 제외 |

- **캐릭터명 매칭**: 트림 후 정확 일치(대소문자 구분은 이름 그대로 — 한글 중심이라 무의미).
  **동명 캐릭터가 2명 이상이면 배정 보류** — 그 폴더는 "기타 이름" 행처럼 처리(신규는 링크
  세트로 편입)하고 요약에 "동명 캐릭터 N명 — 폴더 '가온' 배정 보류"로 고지한다. 어느 한 명을
  임의로 고르는 것은 오배정이고, 오배정은 생략보다 나쁘다(R-1과 같은 취지).
  링크 세트로 들어가므로 인앱에서 한 장만 올바른 캐릭터에 배정하면 세트 전체가 따라간다
  (부드러운 실패 — 결정 D3의 근거).
- **캐릭터 배정 "이동"의 범위**: 단독 소유(캐릭터 소유자 1명 이하) 이미지에만 적용한다.
  캐릭터 소유자가 2명 이상인 이미지는 내보내기가 `_공유/`로 분류하고 받아오기가 반영을
  제외한다(위 표). 작품·세계관 소유는 이동 판정과 무관하며 불변이다(1장 불변식).
- **처리 후 이동(D5)**: 반영·편입에 성공한 원본은 `_처리됨/<원폴더명>/`으로 이동한다.
  이동 실패(SAF 권한·이름 충돌) 시 파일은 그대로 두고 **지문(내용 무관: 상대경로+크기+수정
  시각)을 기록**해 다음 스캔에서 중복 편입을 막는다(지문 저장은 SharedPreferences —
  DB 스키마 변경 없음). 실패·보류 파일은 이동하지 않는다(남아 있는 것 = 미처리의 표식).

## 4. 받아오기 흐름 (PR-1)

1. **나열**: SAF 트리에서 대상 파일 목록 수집(이미지 확장자만, `_처리됨/` 제외, 2단계 이상
   깊이는 계수만). 총량 확정 → 진행도 시작.
2. **계획**: 순수 플래너(6장)가 파일 목록 + 캐릭터 사전 + 토큰 사전 + 현재 배정으로
   "편입/이동/해제/링크/보류" 계획과 고지 목록을 만든다.
3. **확인**: 요약 다이얼로그로 사전 고지(신규 N·배정 이동 M·배정 해제 K·링크 세트 s개·보류
   목록). **실행은 항상 명시 확인 뒤** — 폴더 재배열은 대량 메타 변경이라 조용히 반영하지
   않는다(이미지 탭의 링크 확장 사전 확인과 같은 취지 — 조용한 확대 금지). 진입 감지
   배너(5장)를 탭해 왔어도 이 확인은 거치게 한다.
4. **실행**: 항목 단위로 완결 처리(신규 편입은 기존 `ImageImportHelper.importImage` 압축
   파이프라인 재사용, 배정 변경은 트랜잭션). 진행도 갱신, **취소 = 중단 시점까지 반영 + 요약**
   (항목 단위 완결이라 반쪽 항목이 없다).
5. **마무리**: `CharacterImageAutoLinker.resyncIfEnabled` 1회 호출(배정 변경분의 자동 링크
   수렴 — 기존 진입점들과 동일 규약), 처리분 `_처리됨/` 이동, 결과 요약(성공/보류/실패 각
   개수 + 보류·실패는 파일명 목록), 이미지 탭 재로딩.

## 5. 진입점·설정 UI

- **이미지 관리 탭 메뉴**에 추가: "정리 폴더 받아오기" / "정리 폴더로 내보내기(PR-2)" /

  플로우로 안내.
- **진입 감지(D5)**: 이미지 탭 진입 시 폴더가 지정돼 있으면 비동기로 신규 후보 개수만 센다
  (나열만 — 실패·지연 시 조용히 생략, 수동 메뉴가 항상 있다). 있으면 배너/칩
  "정리 폴더에 새 이미지 N장" → 탭 = 4장 3단계(확인)로 진입.
- **SAF**: `ACTION_OPEN_DOCUMENT_TREE` + `takePersistableUriPermission`. URI는
  `ImageSettingsStore`에 문자열 키로 저장. 권한 소실(폴더 삭제·권한 회수) 시 "정리 폴더에
  접근할 수 없습니다" + 재지정 경로 고지(설정 자동 해제하지 않는다 — 사용자가 상황을 보고
  결정).
- **텍스트**: 새 설정·메뉴에는 R-25 목적문 의무 + `tools/check_text_style.sh` 통과.
  정리 폴더 설정 목적문 초안: "폴더를 지정하면 그 폴더에 넣은 이미지를 이미지 탭에서
  받아올 수 있고, 정리용 내보내기의 대상 폴더로 쓰입니다."

## 7. 실패·경계 사례 (요약 고지 의무 — 조용한 유실 금지)

| 사례 | 처리 |
|---|---|
| 동명 캐릭터 폴더 | 배정 보류 + 링크 세트 편입 + 고지(3장) |
| 같은 토큰이 두 위치에 | 그 토큰 반영 보류 + 고지 |

| 2단계 이상 깊이 | 무시 + 개수 고지 |
| 이미지 아닌 파일 | 무시 + 개수 고지 |
| 편입 실패(손상·복사 실패) | 실패 계수 + 파일명 고지, 원본은 이동하지 않음 |
| `_처리됨` 이동 실패 | 지문 기록으로 중복 방지 폴백(3장) |
| SAF 권한 소실 | 접근 불가 고지 + 재지정 경로(5장) |
| 공유(캐릭터 2+) 토큰 파일 | 반영 제외 + 고지(3장) |
| 취소 | 중단 시점까지 반영 + 요약(4장) |
