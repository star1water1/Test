이 목업이 검증하는 것 (이식 체크리스트)

  • 그림 교체 — 가산 혹(뾰족함 구조 차단)·스필≤3.6·W-아크·강체 플랭크 푸시·z-순서 팔·힙 플래토. 상수는 재저작 스냅샷 그대로.
  • 가슴 핸들 = W-아크 가장자리 (P7) — 역산은 아크 폭 → massBase → 컵차 닫힌 식. 아크가 흉곽 폭에 포화되면 핸들이 경고색이 되고 더 큰 컵은 슬라이더로.
  • 🎲 3축 + 프리셋 (P5) — 몸통·가슴·힙 독립 셀렉터 + 프리셋 세트. 어휘는 전부 긍정 프레이밍, 분포는 장르 상향(슬렌더도 컵차 8~12).
  • 측면 토글 (P10) — 같은 수치의 파생 뷰, 표시 전용(핸들 없음). 편집기·크게 보기 양쪽.
  • 클램프 배선 (4-2) — 축별 clamped → 해당 핸들 경고색 + 한계 캡션. 값은 절대 불변.
  • 카드 재편 (P8·P6) — 3축 요약 칩 + 라인 1개가 핵심층, 전문 지표는 장르어 번역(수치는 부제), 목표 비율 개명, 축별 순위.
  • 고지 2건 (P9·P4) — 인치 휴리스틱(검증→알림→교정), 여성 성인 기준 1줄, 컵 "장르 감각 근사" 부제.
  • 테마 — 색 하드코딩 0. 흑색 저불투명 셰이드 + CSS 변수라 라이트/다크 자동 대응.
