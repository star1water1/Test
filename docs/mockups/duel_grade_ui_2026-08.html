대결 등급 산정 UI 목업 — B-113 (첫 슬라이스)

설계 정본은 docs/feature_roadmap_2026-08.md 4장이다. 왼쪽이 필드 편집 다이얼로그 고급 탭 '연동' 구획의 대결 등급 산정 섹션(컷 편집기 = 100% 총량 구간 슬라이더 — Q2 사용자 제3안), 오른쪽이 [등급 반영] 미리보기다. 예시는 실사용의 어려운 경우 (9단 등급 F~SSS)로 그렸다 — 좁은 구간의 라벨 교차 배치와 탭 선택+스테퍼가 그래서 있다.

  • 합은 언제나 100% — 구분선을 끌면 이웃 구간만 줄고 늘어난다(총량 고정). 검증은 '단조 비감소'다.
  • 드래그 = 러프, 탭 선택 + 스테퍼·숫자 = 정밀(0.5% 단위). 좁은 구간은 라벨을 위아래로 교차 배치하고, 그려지지 않는 폭은 선택 시 말풍선으로만 보인다.
  • 구분선 둘이 겹치면 0% 구간(안 쓰는 등급) — 겹친 자리 근처를 탭하면 어느 경계인지 목록으로 물어 고른다.
  • 라벨 집합은 필드의 실효 등급 표가 정한다 — 체계 개명은 컷이 따라가고, 삭제된 라벨의 컷은 다음 등급에 합쳐진 뒤 이 섹션이 사유를 말한다(4-2장).
  • 축이 없거나 다른 세계관 것이면 슬라이더 대신 사유 한 줄이 선다(오배정 이중 방어 — 4-2장).
